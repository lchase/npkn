# npkn

A local-first notes app. These are the terms its notes, features and integrations are described in.

## Language

### GitHub pull requests

**PR state**:
Where a GitHub pull request stands, as GitHub reports it: draft, open, merged or closed.
_Avoid_: status, PR status

**Badge state**:
What a pull request badge shows: a PR state, or checking, no access, token rejected, or rate limited (shown with the
last known PR state).
_Avoid_: status, badge status
